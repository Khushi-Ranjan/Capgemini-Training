# Capgemini Training – Java Learning Repository

This repository documents my hands-on learning and practical implementation work completed during the **Capgemini Technical Training Program**. It serves as a structured collection of exercises, classroom practice, and assignments focused on building strong foundations in **Core Java and backend development technologies**.

The goal of this repository is to maintain a clear record of concepts learned, problems solved, and real coding practices applied throughout the training journey.

---

## Overview

The repository contains a collection of Java programs, mini-projects, and practice exercises organized according to the topics covered during training. Each section demonstrates the practical application of programming concepts rather than only theoretical understanding.

Key focus areas include:

- Core Java Programming
- Object-Oriented Programming (OOP)
- Exception Handling
- File Handling
- Java Collections Framework
- Stream API
- JDBC Database Connectivity
- Hibernate ORM
- Multithreading
- Code Structuring & Best Practices

---


Each folder contains Java programs demonstrating the concept associated with the respective topic.
